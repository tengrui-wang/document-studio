# 需求与开发约定

目标：Windows 10/11 独立中文 Document Studio，长期维护，通过 GitHub 发布。Python + PySide6，成熟文档库、模块化架构，常规操作本地执行，翻译仅云 API，不部署本地大模型。不得上传私人文档、密钥或敏感数据。

页面：首页、格式转换、文档翻译、PDF 工具、Word 工具、任务中心、AI 模型管理、设置。拖拽/批量、另存、输出目录、进度、错误、取消、重试、打开结果；高级参数折叠。没有 API 配置不能阻断离线功能，不指定默认模型。

转换：PDF → DOCX 尽量保留文字、图片、表格、公式、排版；明确扫描/复杂公式限制。DOCX → PDF 使用 Word 或 LibreOffice。

翻译：中英文及扩展语言，保留图片/表格/公式/标题/结构；长文档分块、术语、失败重试和断点；防漏译、重复、乱序；默认新文件。复杂原版式 PDF 翻译可后续集成成熟方案，不能假称已完成。

API：多服务商/多模型、自动模型列表、手动模型/地址、翻译模型下拉切换、连接测试、错误和 Token 统计，Windows 安全凭据保存密钥，不写普通配置和日志。

PDF：合并、拆分、提取页、旋转、图文提取、浅色背景白化、黑白打印、前后预览。Word：字体、字号、行距、段间距、页边距、替换与标题处理；不拆毁表格/图像。

交付：源代码、实际可运行软件、安装包或正常自动构建、GitHub 状态、使用说明与已完成/未完成/优化清单。记录可恢复进度并及时提交。优先实际可用核心，不做全面 UI、多分辨率或反复重构；必要功能测试、安全检查和构建验证。
